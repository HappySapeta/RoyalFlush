### RoyalFlush

#### How to build?

1. Launch *UpdateSubmodules.bat*. This will update the plugin submodules.
2. Launch *InstallPrerequisites.bat* and follow the onscreen prompts to install Visual Studio Build Tools.
   (Workloads and components will be preselected. You only need to click the install button.)
3. Launch *Build.bat*. This will build the editor binaries and the project will become ready for launching.
4. Open *RoyalFlush.uproject*.
   Confirm rebuilding modules if prompted.
   If the engine displays a warning about missing modules, proceed without installing the modules if that is an option.
